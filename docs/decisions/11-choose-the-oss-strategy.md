# Choose the OSS, upstream, governance, and grant strategy

Type: `research`
Status: `open`
Blocked by: 10

## Question

Which license, governance model, upstream relationships, contribution path, and verified grant opportunities best support the chosen OpenUI Dioxus scope?

## Adapter and platform implication

The OSS strategy must decide adapter package ownership, public Rust API and contract evolution, certification governance, and upstream relationships with Dioxus Components, Rust/UI, and Dioxus Primitives. `v0.1` adapters remain statically compiled. Any later no-recompile binary distribution profile requires a separate evidence-backed decision; third-party adapters may evolve independently only if conformance and compatibility evidence stay public.
